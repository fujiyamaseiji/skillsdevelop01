# ECサイト 機能仕様書

作成日: 2026-03-16

---

## プロジェクト概要

Vite + React + TypeScript + Sass で構築したシンプルなECサイト。
商品一覧の表示・カート機能・在庫管理・注文機能を実装。

---

## 技術スタック

| 項目 | 内容 |
|---|---|
| ビルドツール | Vite |
| フレームワーク | React |
| 言語 | TypeScript |
| スタイル | Sass（BEM記法） |
| ルーティング | React Router |
| データ管理 | JSONファイル（src/data/products.json） |


## 機能一覧

### 1. 商品一覧ページ

- products.json から商品データを取得して表示
- 3カラムグリッドレイアウト（レスポンシブ対応）
- 商品カードをクリックで詳細ページへ遷移

### 2. カート機能

- 「カートに入れる」ボタンで商品をカートに追加
- ヘッダーにカート合計個数をバッジ表示
- カートの個数が在庫数に達したらボタンを非活性・「在庫上限」表示

### 3. カートモーダル

- ヘッダーのカートアイコンクリックで表示
- カート内の商品名・価格・個数を一覧表示
- 合計金額を表示（税込）
- 「注文する」ボタンで注文確定

### 4. 注文機能

- 「注文する」ボタン押下で確認ダイアログを表示
- OK で注文確定：
  - カート内の各商品の在庫数をマイナス
  - カートを空にする
  - 注文完了メッセージを表示
  - モーダルを閉じる
- キャンセルでダイアログを閉じる

### 5. 在庫管理ページ

- 全商品の在庫数を一覧表示
- ＋ / − ボタンで在庫数を増減（0以下にはならない）
- 在庫数の変更はアプリ全体にリアルタイム反映

### 6. 在庫連動表示

| 在庫状態 | 表示 |
|---|---|
| 在庫あり | 通常表示・カートに入れるボタン有効 |
| カート個数 = 在庫数 | ボタン非活性・「在庫上限」表示 |
| 在庫 0 | 価格に打ち消し線・「SOLD OUT」表示 |

## 状態管理

App.tsx で以下の状態を管理：

| state | 型 | 内容 |
|---|---|---|
| products | Product[] | 商品データ（在庫数含む） |
| cartItems | CartItem[] | カート内商品リスト |
| isCartOpen | boolean | カートモーダルの開閉状態 |
